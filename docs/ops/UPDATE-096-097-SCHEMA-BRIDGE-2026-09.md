# 09.6→09.7 同数据库结构迁移能力过渡版

## 目的与边界

本候选版以正式 `2026.09.6` 的 `ice-2026.09.6-8f65c5cd328f` 为准确源版本，面向由 `09.5→09.6` 在线升级而来的旧库安装。第一跳只更换代码 Release：不修改企业数据库结构、配置、画布或素材，也不在旧库登记 schema 版本。正式源版本的数据库快照必须与目标版本逐字段相同，目标 Manifest 继续声明 `same-schema-no-migration` / `code-release-pointer`。

目标代码内预置唯一的 `1→2` 真实迁移步骤 `ice_096_security_schema_v2`。步骤为旧库增加主线已有的安全审计和引导生命周期结构，由现有迁移引擎先备份、再原子登记版本与执行；步骤校验和绑定实际 DDL 定义。它在本次第一跳**不会执行**。旧库升级第二跳时，才能使用这份已安装的更新器运行该步骤。

不得把本候选版视为已完成数据库迁移、部门任务业务表或通用 `09.6` 全部安装形态兼容。`09.6` 全新安装、现场非标准库和已经发生结构漂移的安装须分别核对数据库证据；身份不匹配时停止，不绕过验证。第一跳失败只切回旧代码指针；第二跳失败须恢复数据库和代码指针，无法证明一致则保持 `RECOVERY_REQUIRED`。
