日期：2026-10-31。适用于本地 `codex/character-editor-assets-20261029` / `a2a6831` 未提交候选。首版前84项开发增量保留；本次R2继续修改首版，不代表正式发行或设备验收。

维护责任：共享画布前端维护侧栏、拖动来源、落点和主题；两类编辑器分别维护原节点拖动/位置恢复与原插入/保存路径；原素材库维护者负责目录、媒体副本和Gateway授权；质量维护者维护定向检查，负责人确认实际体验。[当前状态](../CURRENT_PROJECT_STATUS.md)与[路线图](../roadmap/DEVELOPMENT-ROADMAP-2026-2027.md)分别记录事实和后续范围。

## 当前交互

- 直接拖动画布节点的主体或原拖动表面，松开到文件夹或下方素材区即可整理，无须专用悬浮手柄。拖到下方：库内素材页保存至当前文件夹；当前画布页保存至待整理。播放按钮、音量和进度条保留原操作。
- 编辑器现有拖动接入共用的 `previewNodeDrag/dropNodeDrag`；命中侧栏时保存素材并恢复原节点位置，不新增画布节点；未命中时继续原画布移动。智能画布的多图缩略图已有拆出动作，收藏后只撤回本次临时拆出并恢复源图片，不用整页旧快照覆盖后续任务数据。
- 区分画布来源与库内来源：画布节点/当前画布缩略图拖回画布不创建副本；库内素材明确拖回画布或点击加号才新增复用节点，仍走原插入和保存。
- 成功反馈位于侧栏底部，约2.5秒恢复默认文案，没有“已放入画布”悬浮框或手动关闭步骤。撤销独立保留；失败提示在侧栏可读，不自动重复未知请求。
- 可切换Gateway允许访问的既有资产库，或新建产品/用途资产库；每个库使用自己的原分类。支持按产品类型、款式等自建文件夹。选择仅存当前浏览器会话，按账号隔离，不改变全局其他使用者的默认库。
- 新建资产库、文件夹均有明确取消按钮，并支持Esc；取消不写接口、不创建空记录，提交后表单收起。切换库时退出未提交表单，避免把名称写入错误目标。
- 图片、视频、音频共用原媒体分类/副本逻辑；文件夹内可混合放置。视频/音频提供原生播放器，图片使用缩略图；文件夹封面使用对应媒体标识。原分类的 `type=image` 是既有媒体目录语义，并非新建独立音视频系统。
- 同来源在同一文件夹去重；同操作ID重复受理可查到原结果。分类间移动沿用原move元数据接口，不再复制字节。新收藏仍是现有素材副本语义，未引入稳定AssetVersion或只存引用的新架构。
- 撤销收藏仅移除目录记录、保留可能被画布引用的副本字节；撤销移动恢复原分类。库已删除/权限已变化时停止，不静默回退到另一库写入；撤销绑定原库。原图与旧节点保留。

## 复用与接口增量

共用 `static/js/canvas-asset-shelf.js/css` 维护目录请求、侧栏和落点；两类画布复用现有节点拖动、媒体展示和保存，不新建资源、任务或保存系统。来源和目标继续由Gateway原对象Owner与资源授权检查；界面提供库选择不授予新权限。

| 原接口 | 兼容增量与原因 |
| --- | --- |
| POST /api/asset-library/libraries | `reference_shelf=false`为可选默认值；为true时采用Gateway可信账号标记个人库。R2改为同账号、同库名复用，支持创建不同产品库；旧请求行为保留。 |
| POST /api/asset-library/items | 可选 `classify=true`、`collect_request_id=""`；本侧栏明确false，整理不触发已有AI分类。失败只清理本次新副本。 |
| DELETE /api/asset-library/items/{id} | 可选 `keep_file=false`；撤销使用true，只撤回记录。默认删除先提交元数据再清理文件，CAS失败不误删。 |
| 原categories、items/move及GET | 沿用原行为及授权，原资产库入口可继续访问新增分类和媒体。 |
