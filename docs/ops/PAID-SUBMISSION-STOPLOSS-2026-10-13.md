# 付费请求止损与画布原任务持久续查

2026-10-13。沿用唯一开发路线图阶段 4.1，继续现有 #123，不创建重复工作包。候选实现与主线、CI、正式发行分别记录；Release 仍为 v2026.10.1。

## 使用效果

正常提交与画布操作流程保持现有入口。图像/视频提交遇到网络中断、5xx、非 JSON 或无法识别的成功响应时，提示 `PROVIDER_SUBMISSION_UNKNOWN`，要求核对供应商任务与账单。只有明确接口不存在/不受支持的拒绝响应才允许切换兼容端点；查询重试只发 GET/HEAD，不重新生成。

已取得任务 ID 的图像/通用视频查询中断保留原 ID。画布通用异步图像在收到上游 ID 后、第一次轮询前写入既有原子回执；批量请求按成员保存 ID 和已取得图片。中断或重启后，经典/智能画布沿用“查询结果”，优先由本地任务 ID 续查已绑定的原任务。查询成功写回同一回执、原节点和画布；重复查询已保存结果不再访问供应商。供应商明确 FAILED 仍保留失败，结果不明不自动再生成。

本包沿用现有错误区域和查询入口，不增加新的前端页面、审批或用户接口配置。后续页面/交互变更先向负责人说明入口、流程和效果设计。

## 实现边界

- `enterprise/providers/submission.py` 共用明确拒绝判断、未知结果错误、提交 JSON 校验和只读查询重试；不访问数据库、素材目录或 Windows 能力，不建设动态插件框架。
- `main.py` 选择既有供应商路径并调用该模块；删除原有重复重试实现和视频 HTML 后再次提交路径。Zhenzhen 内置图像参数适配保持独立。
- 通用图像/视频兼容端点的付费 POST 单次提交；客户端明确拒绝之后的兼容路径单列。供应商专属分支、不同幂等协议与计费结果不外推。
- 复用 `CanvasTaskJournal` 的回执、原任务 ID 和无自动重提恢复契约；不增加数据库 Schema 或第二套任务存储。
- `enterprise/canvas_image_recovery.py` 负责回执绑定、原任务续查、并发查询单飞、批量成员结果和结果投影；`main.py` 仅接线及复用已有供应商查询/文件归档。两类画布共享 `static/js/canvas-task-query.js`，不复制查询请求实现。
- 新增 `POST /api/canvas-image-tasks/{task_id}/reconcile`：客户端不提交供应商地址、Key 或上游 ID；Gateway 按原本地任务归属授权。管理员检查他人任务时，结果资源仍归原用户，不变成管理员的资产。
- 当前供应商 ID、地址及查询协议须与接受时一致；Key 可正常轮换但不进入回执。地址/协议变更前先阻断查询，不向新供应商发送旧任务身份。查询 HTTP 错误只显示状态码及配置检查提示，不回显原始响应/密钥，不把查询失败当作供应商生成失败。
- 部分结果被保留并明确提示其余请求未确认/失败，不能称整批成功；提示写入已有生成日志。没有已受理 ID、也没有本地已取得结果时不猜测恢复，不自动重提。

## 数据与部署兼容

`journal_version=1` 保持不变，`provider_receipts` 是既有 JSON 回执的可选增量字段。旧回执仍可读，旧查询入口仍保留；没有新 SQLite 表或启动时数据库迁移。新增回执不存请求正文、参考图字节或 API Key，查询绑定不返回给前端。复用既有 task/data 根、原子写入和单个 Upstream 写入者；不提前引入分布式调度或另一套存储。

## 验证与收益

模拟供应商覆盖：POST 禁止瞬态重试、GET 可重试；编辑响应丢失和 503 单次提交；明确 404 后兼容成功；视频代理 POST 单次提交；图像/视频 HTML、空 JSON、错误形状不再提交；5xx 中的“接口不支持”文字不授权重提；已受理图像/视频查询中断保留 ID；供应商明确失败保留失败；未知回执重启后仍可读取且不能重新领取。关联持久回执检查共 13 项通过，没有真实付费请求或客户操作。

直接收益是减少响应丢失时的重复费用风险、保留可查任务身份，并减少入口文件里的重试/错误规则。没有供应商账单和使用统计，不能量化实际节省金额。

## 仍待推进

本包不等于完整持久任务中心。Provider Attempt、受理前后事实源、程序在受理和保存 ID 之间崩溃、批量部分成功、独立 Worker、自动查询对账和费用账本仍随阶段 4.2/4.3 落实。当前视频接口尚没有统一持久回执；PS 企业认证、素材扩展真实宿主、客户付费模型验收仍按各自范围记录。

上述初轮限制中，通用画布图像“已收到 ID 后尚未进入轮询”的中断窗口及批量成员保留/原任务续查已在本轮补齐。HTTP 响应尚未收到或 ID 尚未成功保存的窗口仍只能登记未知、人工核对；不能凭本次回执宣称供应商幂等协议、完整 Provider Attempt 或自动费用对账已完成。专属 CLI、RunningHub、同步在线生图页面、视频、取消和回调没有由本次通用图像钩子全面覆盖。
