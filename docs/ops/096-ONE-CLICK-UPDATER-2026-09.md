# 09.6 现场安全变体一键升级工具

更新日期：2026-09-30

## 目标

向已知受影响的 `ice-2026.09.6-8f65c5cd328f` 客户安装提供一次性图形化升级入口，替代人工 PowerShell 命令。该工具只接受已复核的 28 对象安全治理数据库状态，并将其升级到已发布的 `2026.09.9` 正式版。

## 用户流程

1. 用户双击 `Infinite-Canvas-Enterprise-096-to-099-Updater-x64.exe`。
2. 工具自动检测安装目录；无法检测时由用户在图形页面选择。
3. 用户确认当前没有未完成的 AI 任务。
4. 工具校验内嵌资产、现有 Release、Manifest 与数据库指纹。
5. 备份数据库，停止服务，执行已审查迁移，切换版本并健康检查。
6. 成功时显示中文结果；失败时由现有更新引擎恢复数据库和版本指针。
7. 结果和脱敏诊断 ZIP 写入该安装根目录的 `staging/operator-diagnostics` 目录。

## 安全边界

- 更新器固定绑定一个源 Release、源 Manifest SHA-256 和一个目标版本。
- 发布包、Manifest、文件清单、升级脚本和工具元数据在运行前按大小和 SHA-256 逐项校验。
- 调用旧版 Python 前先校验源 Manifest 和 Python EXE 指纹；安装目录及诊断目录的全部祖先不得为符号链接或重解析点。
- 更新器不调用 PowerShell、`cmd.exe` 或系统 Python，只使用已校验 09.6 的内置 Python `-I -B`。
- 更新器不扫描、删除或修改所选安装根目录以外的项目和数据。
- 未知 Release、未知数据库指纹、资产不匹配或恢复不可确认时一律阻断。
- 按发布包最长文件名计算安装路径预算，超出旧版 Python 的 Windows 路径边界时在升级前提示。
- 已回退和恢复待确认分别提示；诊断导出失败不会把成功升级误报成失败。

## 验收与交付

- 定向单元测试、路径写入审计和双构建一致性作为本次代码验证。
- 已下载并校验准确的 09.6 和 09.9 发布资产，以 09.6 内置 CP314 在隔离安装副本上完成成功迁移、目标启动故障回退及数据保留演练。共享 Supervisor 切换使用测试回调；成功场景另验证目标独立 HTTP 启动。
- 编译 EXE 另外执行缺少业务确认、源 Python 不匹配，以及真实内置 Python 对损坏安装状态的拒绝和诊断导出场景。
- 测试设备的图形操作、真实 Supervisor 重启仍由实际安装验收确认，不将独立干净 Windows 主机设为前置要求。
- 交付包标为验收包，明确是否签名；现装 09.9 设备继续使用页面更新，无需运行本工具。

自动化验收可用 `/VERYSILENT /INSTALLROOT=... /CONFIRMNOACTIVETASKS=1`，客户使用时只需双击 EXE。四项核心发布资产的归档、指纹和构建记录随工具交付。

## 发布边界

仓库中包含可审查的 Inno Setup 源码、固定工具链策略和可重现构建脚本。产品发布前还必须完成：定向测试、两次构建一致性校验、真实 09.6 安装副本成功/回退演练、下载回验以及发布资产 SHA-256 记录。未配置 Authenticode 证书时必须明确标记为未签名，不得声称已签名。
