# Infinite Canvas Enterprise 2026.09.8 正式过渡版

## 本次更新

- 支持从准确的正式版 `2026.09.6` 安装升级；下载、完整性校验、切换和启动检查仍由更新中心执行。
- 更新中心核对目标版本声明的准确来源、数据库结构和更新器能力；不兼容版本会显示原因并禁止碰运气升级。
- 为后续需要迁移数据库的版本预置受控迁移步骤。本次不修改客户数据库结构，也不迁移画布、素材或配置目录。
- 保留作业记录和失败回退机制。跨多个版本的自动连续升级仍在开发中，不能将本版视为该能力已交付。

## 升级范围与已知限制

- 本版是正式通道的**同数据库结构过渡版**。仅在准确 `2026.09.6` 的三项资产与数据库证据通过核验后开放升级；其他来源版本必须另行验证。
- 旧版管理后台的“设为管理员”与“操作授权”页面仍可能返回 `403 TRANSITIONAL_POLICY_DENIED`。这是旧页面与受控权限策略不匹配，不能通过放宽后端授权来修复。新管理流程需要数据库迁移，安排在后续独立改表版交付；本版不宣称已解决该问题。
- 发布候选使用准确 `2026.09.6` 安装副本进行正常升级和注入目标启动失败两条演练（2 项通过）：数据库字节、画布归属、配置和素材均保持不变；正常路径通过目标便携预检，并由目标包内 Python 在独立回环端口返回 HTTP 200。演练的切换启动回调为测试桩，不等于共享 Supervisor 或客户设备实测。
