# OPS-3B 隔离升级与恢复演练记录

状态：定向验证已完成，待代码审查；真实跨进程演练为可选补充，不构成正式 Release 或客户升级批准。

## 范围与安全边界

自动化验证只使用临时安装根、临时数据库和模拟 Runtime，不使用客户设备、现有业务数据库或旧热修分支。项目负责人已明确：不要求另备干净 Windows 设备或用户环境，不为真实跨进程演练阻断后续开发。若未来已有合适的临时 CI 环境和当前版本构建产物，可补做真实进程/端口检查；该证据不是本阶段必需条件。

这是对历史 OPS 文档中“干净 Windows 环境演练为前置门禁”的当前调整；历史记录保留作为当时决策，不再用它阻断 #115 的合并或后续开发。正式客户 Release 的兼容性与恢复审查仍单独进行。

`enterprise/tests/update_mvp_1_windows_smoke.py` 以前会临时搬动当前用户的 LocalAppData 产品目录。现改为：只要两个产品目录之一已存在，就在创建证据目录和执行升级前拒绝；仅清理本次创建、带随机归属标记的目录。隔离工作区位于指定证据目录下，清理前核对绝对路径、归属和 reparse 边界。不得为了通过演练而手动移动、删除现有用户目录。

| 场景 | 结果 | 证据边界 |
