# Infinite Canvas Enterprise 2026.09.9 正式版

## 本次更新

- 首次以受控的版本化迁移，将数据库结构从旧版基础形态推进到安全治理结构。迁移前会生成数据库备份，目标启动或健康检查失败时恢复数据库和版本指针。
- 修复 `2026.09.6` 发布证据与已启用安全治理的安装数据库不一致所造成的升级阻断。不会删除审计表、引导标记或客户数据，也不会改写旧版发布包。
- 保留画布、素材及安装根目录中的配置；它们不随代码 Release 替换。
- 对准确 `2026.09.6` 安全治理变体提供独立受控桥接工具。该例外必须同时验证源 Release、Manifest、全部 28 项数据库定义、审计记录和引导标记；普通在线更新不会仅凭版本号或对象数量跳过校验。

## 升级路径

- 已通过正式 `2026.09.8` 且数据库为准确 18 对象旧结构的设备：从管理后台选择 `2026.09.9`，由更新中心执行备份、迁移、切换、健康检查及必要时的恢复。
- 已安装准确 `2026.09.6`、数据库含完整安全治理 28 对象的设备：旧更新器无法安全执行此迁移，不能在页面直接跳到本版；需先通过只读现场核验，再按单独提供的桥接工具和操作说明执行。
- 其他安装来源、结构指纹或未完成恢复作业不在以上路径内；更新中心应显示不兼容原因并停止升级，不应手工绕过。

## 边界

- 本版不宣称支持任意旧版本直升，也不包含自动跨多跳升级。
- 管理后台旧权限操作的 `403 TRANSITIONAL_POLICY_DENIED` 不应通过放宽安全策略解决；本次只处理升级和数据库结构，不宣称已交付新权限治理页面。
- 客户设备的只读指纹、安装副本迁移与失败回退、正式资产完整性和 CI 均须通过后才可发布。候选代码和仓库测试通过不等于客户现场已验收。
